Four complete apps

Four complete apps, each one HTML file, built the way the guide recommends and checked by the test suite. Open one to try it here, read-only, or download it and open it in HTML Clay to edit it and watch it save.

Reading list The starter skeleton.html

The smallest correct app: a sortable reading list with saved checkboxes, a derived summary, a filter that stays in your tab, live sync and undo. Start every new file from it.

Loads clay.js?plugins=sync,sortable,undo,indicator&exclude=richclay
